# 单集工作台 v2 设计（简化交互 + 剧本/分镜重新生成）

- 日期：2026-10-10
- 依据：`docs/notes/2026-10-10-research-global-video-workbenches.md`、`docs/notes/2026-10-10-research-cn-manju-platforms.md`；上一轮改造 `docs/superpowers/plans/2026-10-10-ux-flow-overhaul.md`
- 取代：总设计 `2026-10-07-ai-studio-design.md` 第 11 节中「剧本 / 资产 / 导演台 / 后期与导出」分页的界面方案（流程本身不变）

## 1. 问题

用户反馈「工作台太复杂、不好交互」，并要求剧本和分镜能重新生成。现状：
- 一集拆成 剧本 / 角色 / 导演台 / 导出 四页，来回跳；角色页两个角色就铺满表单。
- 「运行剧本 / 运行分镜」在输入没变时会被跳过，必须先勾「强制重跑」——用户以为不能重新生成；分镜只能整集重跑。
- 导演台每镜多个按钮 + 工具栏，信息密度高。

## 2. 调研得出的方向（两份报告的共同结论）

1. 一集一个主工作面（镜头卡片网格），剧本、角色在侧栏 / 抽屉。
2. 阶段确认、每阶段一个「下一步」；**首帧确认门**：整集首帧出完、确认后才排队转视频。
3. 角色是资产卡，深度编辑进抽屉。
4. 镜头卡一个随状态变化的主按钮，其余进「⋯」；候选挂在镜头上。
5. 重新生成分整集 / 按段 / 按镜，先看影响再确认（我们已有影响预估，做成正式能力）。
6. 参数默认收起（智能 / 自定义）。

## 3. 重新生成（阶段 A）

### 3.1 后端
- `RunIn` 增加：`scene_block_ids: list[int] | None`（只对 storyboard 有效：只重写这些段落的分镜）、`note: str | None`（修改意见，≤500 字，去首尾空白，空串视为无）。
- `note` 非空时等同 `force=true`，并写进提示词（`script_structure.md`、`script_visual.md`、`storyboard.md` 的 user 部分末尾加「修改意见：…，在满足原有要求的前提下按此修改」；模板变量 `note`，为空不出现）。
- storyboard 按段：payload 已支持 `scene_block_ids`（`backend/pipeline/storyboard.py` 的 `only`），API 透传即可；按段时不删其他段的镜头、不清孤儿（现有逻辑）。
- 有 `note` 时，storyboard 提示词附上该段现有 llm 镜头（动作 + 台词）作为「上一版」，让模型在其基础上改（`storyboard.md` 可选块 `previous_shots`；无 note 时不附）。
- `GET /api/episodes/{id}/rerun-impact` 增加参数 `scene_block_ids`（逗号分隔）与 `note`（有值时按 force 计算），按段时只计这些段。
- script 阶段不做按段重写（结构是整集一次生成）；整集重写可带 `note`。

### 3.2 前端
- 去掉「强制重跑」勾选框（剧本页与导演台都去掉；导演台的「重拍」本身就是强制）。
- 剧本：还没有段落 → 「生成剧本」；已有 → 「重新生成剧本…」，打开重新生成对话框。
- 分镜：还没有镜头 → 「生成分镜」；已有 → 「重新生成分镜…」。每个段落行上有「重写本段分镜…」。
- 重新生成对话框（共用组件 `RegenerateDialog`）：范围说明（整集 / 第 N 段）、「修改意见（可选）」多行框（占位：例如「第 3 段改成在车底对话」「镜头更紧凑，少用远景」）、实时加载的影响预估（会删几个镜头、几个有选定首帧/视频、保留几个手工镜头、会覆盖什么），按钮「重新生成」（会删除已选定视频时为危险样式）。
- 原文/段落有未保存修改时，对话框里提示并在确认时一并保存（沿用「保存并运行」）。

## 4. 单集工作台（阶段 B）

### 4.1 路由
- 新：`/projects/:slug/episodes/:episodeId`（可带 `?stage=script|cast|keyframes|videos|export&shot=<id>&char=<id>`）。
- 旧的 `/script` `/cast` `/director` `/export` 重定向到新地址并带上对应 stage（`?shot=` 等参数保留）。
- 左侧全局导航「制作流程」改为：项目中心、当前集（工作台）；任务、设置不变。

### 4.2 布局（≥1280 宽）
```
┌ 页头：项目 › 第N集 标题 · 上一集/下一集                                         ┐
│ 阶段条：剧本 ✓ · 角色 2/2 · 首帧 6/6 · 视频 4/6 · 成片 — [下一步：…（约 12 分钟）] │
├──────────┬────────────────────────────────────────────────────┤
│ 左栏 280  │ 主区（随阶段）                                         │
│ 剧本大纲   │  剧本：原文编辑 + 段落列表（重新生成 / 重写本段分镜）        │
│  段落1…   │  角色：角色卡网格（大图 + 状态 + 主按钮）+ 设定（场景/风格） │
│ 角色卡     │  首帧/视频：按段落分组的镜头卡片网格                       │
│  陈师傅 ✓ │  成片：导出面板 + 成片列表                                │
└──────────┴────────────────────────────────────────────────────┘
右侧抽屉：镜头详情（候选、提示词【高级】、对白）/ 角色详情（造型、三视图、资料）
```
- 阶段条每段可点，切换主区；「下一步」是全页唯一主按钮，文案带数量与预计耗时。
- 左栏可折叠；点段落 = 主区切到剧本并滚到该段；点角色 = 打开角色抽屉。

### 4.3 镜头卡（首帧 / 视频阶段）
- 9:16 缩略（首帧阶段显示首帧，视频阶段显示视频 + 播放角标），下方：镜号、时长、动作（两行截断）、台词数、出场角色头像、状态角标（排队/生成中 xx%/失败/已过期/N 张新候选）。
- 一个主按钮随状态：首帧阶段「生成首帧」/「重拍首帧」；视频阶段无首帧时「先出首帧」（跳回首帧阶段并选中）、有首帧「生成视频」/「重拍视频」；失败时「重试」。卡片主按钮用普通样式（全页唯一主按钮在阶段条）。
- 「⋯」：在后面插入、拆分、上移/下移、删除。
- 点卡片 = 打开镜头抽屉；卡片左上角勾选可多选，选中后阶段条主按钮变「对选中的 N 镜生成…」。
- 按段落分组，组头：「第 N 段 · 场景名 · M 镜」+「重写本段分镜…」；手工镜头（无段落）单独一组「手工添加」。

### 4.4 首帧确认门
- 首帧阶段：有缺少或过期首帧时，「下一步」=「生成缺少/过期的首帧（N 张，约 X 分钟）」；全部就绪后「下一步」=「确认首帧，生成全部视频（N 镜，约 X 分钟）」，点击后切到视频阶段并提交。
- 视频阶段同理；全部就绪后「下一步」=「去成片」。
- 预计耗时沿用 `pages/director/estimate.ts`。

### 4.5 角色
- 主区角色阶段：角色卡网格（当前定妆照大图、名字、音色、状态）；缺定妆照的卡主按钮「抽定妆照」。
- 角色抽屉：页签「造型」（定妆照条 + 抽卡栏 + 大图预览/设为当前造型）、「三视图」、「资料」（名字、描述、外观提示词【高级】、核心特征、音色）。复用现有 CharacterCard / TurnaroundPanel 的逻辑拆分而来。
- 场景与风格放在角色阶段主区下方的「设定」折叠区。

### 4.6 不变
- 后端流水线、任务队列、过期判定、提交前置校验、健康检查、任务页、设置页、项目中心与项目详情。
- 已有共用件：useConfirm、Dialog、EditableFields（合并与离开拦截）、useJobNotice、Toasts、HealthBanner、Lightbox、Menu、estimate.ts。
- stages.ts 改为五段：剧本（有段落且有镜头才完成）、角色、首帧、视频、成片。
