# M1 主线（前端 + 网页端验收）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出 AI Studio 的网页工作台（项目中心 / 剧本 / 导演台 / 任务 / 设置 + 顶部常驻任务条），补齐前端需要的几处后端能力（生产态托管前端、WebSocket Origin 校验、导出到 ComfyUI、成片列表、start.ps1），最后在浏览器里把一段梗概跑成带 H3 原生声音的成片，完成 M1 验收。

**Architecture:** 前端是 HTTP API 的又一个客户端，和 `studio` CLI 平级：服务端状态全部放在 TanStack Query 缓存里，按查询键失效刷新；`/api/ws` 推来的 job / log / progress / queue 事件只做两件事——更新进度、让相关查询失效。生成类操作一律 `POST /api/episodes/{id}/run` 提交任务，界面不等结果。开发态 Vite（127.0.0.1:5173）把 `/api`（含 WebSocket）和 `/media` 代理到后端 8700；生产态 `npm run build` 后由 FastAPI 直接托管 `frontend/dist`，只占 8700 一个端口。

**Tech Stack:** React 18.3、TypeScript 5.9（strict）、Vite 8、@vitejs/plugin-react 6、@tanstack/react-query 5、react-router-dom 7、Vitest 5 + jsdom + @testing-library/react 16 + @testing-library/user-event 14、@playwright/test 1.64；后端沿用 FastAPI + pytest（uv）。Node 24、npm 11、Windows 11。

**Spec:** `docs/specs/2026-10-07-ai-studio-design.md`（重点：§4.1 仓库结构与启动方式、§11 界面、§13 测试策略、§14 M1 验收）。后端计划 `docs/superpowers/plans/2026-10-07-m1-backend.md` 已全部完成（171 个测试通过），本计划在 `feat/m1-backend` 分支上继续。

## Global Constraints

- 只监听 `127.0.0.1`：后端 `8700`；Vite 开发服务器 `127.0.0.1:5173`（strictPort），把 `/api`（`ws: true`）和 `/media` 代理到 `http://127.0.0.1:8700`；Playwright 冒烟用临时后端 `127.0.0.1:8711`。
- 前端技术栈固定为 React 18 + Vite + TypeScript（`strict`、`noUnusedLocals`、`noUnusedParameters`）+ TanStack Query + react-router-dom；不引任何 UI 组件库，样式只写在 `frontend/src/styles.css` 一个文件里。
- 前端依赖用 npm 管理，`frontend/package-lock.json` 提交；Python 侧仍用 uv（`uv run pytest`）。
- UI 文案一律中文（按钮、标题、提示、错误、空状态）；后端新增的错误信息也用中文。
- 前端只通过 HTTP API 和 `/api/ws` 与后端交互；媒体一律使用后端返回的 `url`（`/media/...`），不在前端拼文件系统路径。
- URL 里出现的项目 slug 一律 `encodeURIComponent`（slug 可以是中文，如 `提词员`）。
- 生成类操作一律提交任务（`POST /api/episodes/{id}/run`），界面不同步等待生成结果，靠 WebSocket 事件和查询失效刷新。
- 批量/单镜生成时 `RunIn.shots` 传镜头 id 的字符串（`["12"]`），不传 `S01` 这类编号——编号在排序、拆分、删除后会变，id 不会。
- 后端改动沿用已有约定：先写失败测试再实现；异常用 `LookupError`→404、`ValueError`/`JobError`→400、`PermissionError`→403 映射；`uv run pytest` 必须全绿。
- `config.yaml`、`projects/`、`logs/`、`node_modules/`、`frontend/dist/`、`frontend/test-results/`、`frontend/playwright-report/` 不提交。
- git 提交信息不带任何 Claude 署名（不加 Co-Authored-By、Generated with 之类）。
- Vitest 测试不连真实后端（全局 `fetch` 与 `WebSocket` 用替身）；Playwright 冒烟用临时数据目录 + `manual` LLM provider，不需要显卡；只有最后一个任务碰真实 ComfyUI（`http://127.0.0.1:8189`）和 Claude provider。
- 每个前端任务结束时，在 `frontend/` 下 `npm test` 与 `npm run typecheck` 都必须通过。

## Review Focus

1. **中文 slug 出现在请求路径里**（项目"提词员"、"冒烟"）：所有带 slug 的请求都要编码，否则中文路径在代理和后端两侧行为不一致。→ Task 6 `中文 slug 在路径里会被编码`；Task 16 的冒烟用中文项目名走全流程。
2. **后端重启或 WebSocket 断线**：任务条要提示"实时连接已断开"，自动重连，并在重连成功时把所有查询重新拉一遍（断线期间的事件已经丢了），否则界面会一直停在旧状态。→ Task 7 `断线后自动重连，重连成功时全部刷新`。
3. **manual 模式下粘贴了不合格的 JSON**：后端把任务重新置为 waiting_input 并在 `input_request.error` 里写原因；界面要显示这个原因、给出一个清空的新输入框，而不是看起来"提交成功但什么都没发生"。→ Task 14 `上次粘贴不合格时显示原因`。
4. **正在编辑提示词/剧本时，WebSocket 事件触发了重新拉取**：只要服务器内容没变，未保存的编辑不能被冲掉；服务器内容真的变了（保存成功、别处改了）才换成新内容。→ Task 10 `父组件用相同内容重新渲染时不冲掉正在编辑的内容`。
5. **生产态在深链接上刷新、或请求了不存在的 /api 路径**：`/projects/提词员/episodes/1/director` 刷新要返回 index.html；`/api/nope` 必须是 JSON 404 而不是网页；`/..%2Fsecret` 这类路径不能读到 dist 之外的文件。→ Task 4 三个测试。

### Task 1: WebSocket 握手校验 Origin

浏览器发起的 WebSocket 不受同源策略约束：任何网站的页面都能连 `ws://127.0.0.1:8700/api/ws` 偷看任务日志和提示词。HTTP 写请求已经有 Origin 校验（`main.py` 的 `reject_cross_origin_writes`），这里把同一条规则搬到 WS 握手上，并把判定函数挪到 `deps.py` 供两处共用。

**Files:**
- Modify: `backend/app/deps.py`（新增 `LOCAL_ORIGIN`、`is_local_origin`）
- Modify: `backend/app/main.py`（删掉文件顶部的 `import re` 与 `LOCAL_ORIGIN = re.compile(...)`，`reject_cross_origin_writes` 改用 `is_local_origin`）
- Modify: `backend/app/routes/ws.py`
- Test: `backend/tests/test_api_ws_origin.py`

**Interfaces:**
- Consumes: 现有 `api` fixture（`backend/tests/conftest.py`）、`/api/ws` 首条消息 `{"type": "queue", "paused", "counts", "current_family"}`
- Produces:
  - `backend.app.deps.LOCAL_ORIGIN: re.Pattern`（`^https?://(127\.0\.0\.1|localhost)(:\d+)?$`）
  - `backend.app.deps.is_local_origin(origin: str) -> bool`
  - `/api/ws`：带 `Origin` 头且不是本机页面时，握手阶段直接以 close code `1008` 拒绝；不带 `Origin`（CLI、脚本）照常放行

```python
"""WebSocket：推送任务状态、日志、进度、队列状态。"""
from __future__ import annotations

from fastapi import APIRouter, WebSocket, WebSocketDisconnect
from starlette.concurrency import run_in_threadpool

from backend.app.deps import is_local_origin

router = APIRouter(prefix="/api", tags=["ws"])
POLICY_VIOLATION = 1008


@router.websocket("/ws")
async def events(sock: WebSocket):
    # 浏览器里的 WebSocket 不受同源策略限制，别的网站的页面也能连上来看任务日志和提示词；
    # 所以带了 Origin 且不是本机页面的一律在握手时拒绝。CLI 等非浏览器客户端不带 Origin，放行。
    origin = sock.headers.get("origin")
    if origin is not None and not is_local_origin(origin):
        await sock.close(code=POLICY_VIOLATION)
        return
    await sock.accept()
    bus = sock.app.state.bus
    q = bus.subscribe()
    try:
        state = await run_in_threadpool(sock.app.state.manager.queue_state)
        await sock.send_json({"type": "queue", **state})
        while True:
            await sock.send_json(await q.get())
    except WebSocketDisconnect:
        pass
    finally:
        bus.unsubscribe(q)
```

```python
"""把 API 格式工作流转成 ComfyUI 界面可导入的图形格式。移植自 ai_videos/vglib/export.py（自有代码）。

runs/<job_id>/workflow.api.json 里存的是 API 格式 {节点id: {class_type, inputs}}，那是 /prompt
接口吃的；界面「导入」要的是 {nodes:[...], links:[...]}，必须显式声明每个节点的输入插槽、
输出插槽、连线和 widget 取值顺序——这些信息从 /object_info 取。

三个容易踩的点：
  1. COMBO 在 object_info 里可能是字符串类型名而不是选项列表，也得算 widget
  2. 种子类 widget 界面会多挂一个 control_after_generate，LoadImage 多一个上传按钮
  3. autogrow 输入（如 ref_images）实际插槽名是带点的 ref_images.ref_image_0
"""
from __future__ import annotations

import uuid
from collections.abc import Callable
from typing import Any

WIDGET_TYPES = {"INT", "FLOAT", "STRING", "BOOLEAN"}
AUTOGROW = "AUTOGROW"
COLUMN_WIDTH = 420
ROW_HEIGHT = 200


class MissingNodeError(ValueError):
    """object_info 里没有工作流用到的节点类型（ComfyUI 没装对应的自定义节点）。"""


def info_lookup(object_info: dict) -> Callable[[str], dict]:
    def get(class_type: str) -> dict:
        try:
            return object_info[class_type]
        except KeyError:
            raise MissingNodeError(
                f"ComfyUI 里没有节点 {class_type}，装好对应的自定义节点后再导出") from None
    return get


def _opts(spec: list) -> dict:
    return spec[1] if len(spec) > 1 and isinstance(spec[1], dict) else {}


def _tname(spec: list) -> str:
    return "*" if isinstance(spec[0], list) else str(spec[0])


def _is_widget(spec: list) -> bool:
    t = spec[0]
    if isinstance(t, list):
        return True
    t = str(t)
    return t in WIDGET_TYPES or "COMBO" in t


def _is_autogrow(spec: list) -> bool:
    return AUTOGROW in _tname(spec)


def _is_link(v: Any) -> bool:
    return isinstance(v, list) and len(v) == 2 and isinstance(v[1], int)


def _default(spec: list) -> Any:
    t, o = spec[0], _opts(spec)
    if "default" in o:
        return o["default"]
    if isinstance(t, list):
        return t[0] if t else ""
    return {"INT": 0, "FLOAT": 0.0, "STRING": "", "BOOLEAN": False}.get(str(t), "")


def to_ui_graph(api_wf: dict, get_info: Callable[[str], dict]) -> dict:
    ids = {k: i + 1 for i, k in enumerate(api_wf)}
    info = {k: get_info(v["class_type"]) for k, v in api_wf.items()}

    widgets: dict[str, list] = {}
    slots: dict[str, list[tuple[str, str | None, Any]]] = {}
    for k, node in api_wf.items():
        d = info[k].get("input") or {}
        decl = list((d.get("required") or {}).items()) + list((d.get("optional") or {}).items())
        wv: list = []
        sl: list[tuple[str, str | None, Any]] = []
        seen: set[str] = set()
        for name, spec in decl:
            seen.add(name)
            val = node["inputs"].get(name)
            if _is_autogrow(spec):
                continue
            if _is_widget(spec) and not _is_link(val):
                wv.append(_default(spec) if val is None else val)
                o = _opts(spec)
                if o.get("control_after_generate"):
                    wv.append("fixed")
                if o.get("image_upload"):
                    wv.append("image")
            else:
                sl.append((name, _tname(spec), val))
        for name, val in node["inputs"].items():
            if name not in seen and _is_link(val):
                sl.append((name, None, val))
        widgets[k], slots[k] = wv, sl

    links: list[list] = []
    link_id = 0
    inbound: dict[str, list[dict]] = {}
    outbound: dict[str, dict[int, list[int]]] = {k: {} for k in api_wf}
    for k in api_wf:
        ins: list[dict] = []
        for name, t, val in slots[k]:
            if _is_link(val) and val[0] in api_wf:
                src, sslot = val[0], int(val[1])
                if t is None:
                    outs = info[src].get("output") or []
                    t = outs[sslot] if sslot < len(outs) else "*"
                link_id += 1
                links.append([link_id, ids[src], sslot, ids[k], len(ins), t])
                outbound[src].setdefault(sslot, []).append(link_id)
                ins.append({"name": name, "type": t, "link": link_id})
            else:
                ins.append({"name": name, "type": t or "*", "link": None})
        inbound[k] = ins

    rid = {v: k for k, v in ids.items()}
    depth: dict[str, int] = {}

    def dep(k: str, seen: tuple = ()) -> int:
        if k in depth:
            return depth[k]
        if k in seen:
            return 0
        ups = [rid[ln[1]] for ln in links if ln[3] == ids[k]]
        depth[k] = 0 if not ups else 1 + max(dep(u, seen + (k,)) for u in ups)
        return depth[k]

    for k in api_wf:
        dep(k)
    col: dict[int, int] = {}
    pos: dict[str, list[int]] = {}
    for k in sorted(api_wf, key=lambda x: (depth[x], ids[x])):
        c = depth[k]
        r = col.get(c, 0)
        col[c] = r + 1
        pos[k] = [c * COLUMN_WIDTH, r * ROW_HEIGHT]

    nodes = []
    for k, node in api_wf.items():
        d = info[k]
        names = d.get("output_name") or []
        outs = []
        for i, t in enumerate(d.get("output") or []):
            outs.append({"name": names[i] if i < len(names) else t, "type": t,
                         "links": outbound[k].get(i, []), "slot_index": i})
        nodes.append({
            "id": ids[k], "type": node["class_type"], "pos": pos[k],
            "size": [360, 30 + 26 * max(1, len(widgets[k]) + len(inbound[k]))],
            "flags": {}, "order": depth[k], "mode": 0,
            "inputs": inbound[k], "outputs": outs,
            "properties": {"Node name for S&R": node["class_type"]},
            "widgets_values": widgets[k],
        })

    # id 必须是字符串 UUID：界面的 schema 是 z.string().optional()，给 null 会校验失败，
    # 报「无法找到工作流」
    return {"id": str(uuid.uuid4()), "revision": 0,
            "last_node_id": max(ids.values()) if ids else 0,
            "last_link_id": link_id, "nodes": nodes, "links": links,
            "groups": [], "config": {},
            "extra": {"ds": {"scale": 0.75, "offset": [80, 80]}},
            "version": 0.4}
```

```python
"""槽位与候选、媒体文件、导出到 ComfyUI。"""
from __future__ import annotations

import json

from fastapi import APIRouter, HTTPException, Request
from fastapi.responses import FileResponse, JSONResponse

from backend.app.deps import get_or_404, services
from backend.app.schemas import CandidateOut, CandidatePatch, SlotOut
from backend.app.views import candidate_out
from backend.domain.models import Candidate
from backend.domain.slots import select_candidate, slots_for
from backend.engines.comfyui.errors import ComfyError
from backend.engines.comfyui.export_ui import info_lookup, to_ui_graph

router = APIRouter(tags=["candidates"])


@router.get("/api/slots", response_model=list[SlotOut])
def list_slots(owner_type: str, owner_id: int, request: Request):
    with services(request).db.session() as s:
        return [SlotOut(id=sl.id, kind=sl.kind, selected_candidate_id=sl.selected_candidate_id,
                        candidates=[candidate_out(c) for c in sl.candidates])
                for sl in slots_for(s, owner_type, owner_id)]


@router.post("/api/candidates/{candidate_id}/select", response_model=CandidateOut)
def select(candidate_id: int, request: Request):
    with services(request).db.session() as s:
        return candidate_out(select_candidate(s, candidate_id))


@router.patch("/api/candidates/{candidate_id}", response_model=CandidateOut)
def patch_candidate(candidate_id: int, body: CandidatePatch, request: Request):
    with services(request).db.session() as s:
        c = get_or_404(s, Candidate, candidate_id, "候选")
        for k, v in body.model_dump(exclude_unset=True).items():
            setattr(c, k, v)
        s.flush()
        return candidate_out(c)


@router.get("/api/candidates/{candidate_id}/file")
def candidate_file(candidate_id: int, request: Request):
    sv = services(request)
    with sv.db.session() as s:
        rel = get_or_404(s, Candidate, candidate_id, "候选").file_path
    return FileResponse(sv.media.public_file(rel))


@router.get("/api/candidates/{candidate_id}/comfy-workflow")
def comfy_workflow(candidate_id: int, request: Request):
    """把这个候选当时用的工作流转成 ComfyUI 界面格式，作为附件下载，拖进 ComfyUI 就能手调。"""
    sv = services(request)
    with sv.db.session() as s:
        c = get_or_404(s, Candidate, candidate_id, "候选")
        rel, engine = (c.params or {}).get("workflow"), c.engine or "workflow"
    if not rel:
        raise LookupError(f"候选 {candidate_id} 没有记录工作流")
    path = sv.media.abs(rel)  # runs/ 不对外公开，只在这里内部读取
    if not path.is_file():
        raise LookupError(f"工作流文件不存在：{rel}")
    api_wf = json.loads(path.read_text(encoding="utf-8"))
    if sv.comfy_client is None:
        raise HTTPException(503, "没有配置 ComfyUI，取不到节点信息")
    try:
        info = sv.comfy_client.object_info(tries=1, timeout=30)
    except ComfyError as e:
        raise HTTPException(502, f"取不到 ComfyUI 的节点信息：{e}") from None
    graph = to_ui_graph(api_wf, info_lookup(info))
    name = f"{engine}_{candidate_id}.json"
    return JSONResponse(graph, headers={"Content-Disposition": f'attachment; filename="{name}"'})


@router.get("/media/{path:path}")
def media(path: str, request: Request):
    return FileResponse(services(request).media.public_file(path))
```

```python
"""FastAPI 入口：uv run studio-server"""
from __future__ import annotations

import asyncio
from contextlib import asynccontextmanager
from pathlib import Path

import uvicorn
from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import FileResponse, JSONResponse
from starlette.middleware.trustedhost import TrustedHostMiddleware

import backend.pipeline  # noqa: F401  注册各阶段处理器
from backend.app.deps import install_error_handlers, is_local_origin
from backend.app.routes import ROUTERS
from backend.config import Config, load_config
from backend.domain.db import Database
from backend.domain.media import MediaStore
from backend.logging_setup import setup_logging
from backend.queue.events import EventBus
from backend.queue.handlers import HANDLERS
from backend.queue.manager import JobManager
from backend.services import build_services

ALLOWED_HOSTS = ["127.0.0.1", "localhost", "testserver"]  # testserver 是 TestClient 的默认 Host
SAFE_METHODS = {"GET", "HEAD", "OPTIONS"}
BACKEND_PREFIXES = ("api", "media")


def install_local_guards(app: FastAPI) -> None:
    """只服务本机：Host 不是本机名的请求一律 400（防 DNS rebinding）；
    带了 Origin 且不是本机页面的写请求一律 403（防别的网站在浏览器里跨站提交）。"""

    @app.middleware("http")
    async def reject_cross_origin_writes(request: Request, call_next):
        origin = request.headers.get("origin")
        if (request.method not in SAFE_METHODS and origin is not None
                and not is_local_origin(origin)):
            return JSONResponse({"detail": f"拒绝来自 {origin} 的跨站写请求"}, status_code=403)
        return await call_next(request)

    # 后加的中间件在最外层：先查 Host，再查 Origin
    app.add_middleware(TrustedHostMiddleware, allowed_hosts=ALLOWED_HOSTS)


def install_frontend(app: FastAPI, dist: Path | None) -> None:
    """生产态：frontend/dist 存在时由后端直接托管前端，只占一个端口。
    必须在所有 API 路由之后调用：兜底路由不能挡住 /api 和 /media。"""
    if dist is None or not (Path(dist) / "index.html").is_file():
        return
    root = Path(dist).resolve()
    index = root / "index.html"

    def not_found() -> HTTPException:
        return HTTPException(404, "Not Found")

    @app.get("/{full_path:path}", include_in_schema=False)
    def frontend(full_path: str):
        first = full_path.split("/", 1)[0]
        if first in BACKEND_PREFIXES:
            raise not_found()  # 未知的 API 路径要拿到 JSON 404，而不是网页
        if full_path:
            try:
                MediaStore._check_rel(full_path)  # resolve 之前先挡掉 ..、盘符、反斜杠、UNC
            except ValueError:
                raise not_found() from None
            p = (root / full_path).resolve()
            if p.is_relative_to(root) and p.is_file():
                return FileResponse(p)
            if first == "assets" or "." in full_path.rsplit("/", 1)[-1]:
                raise not_found()  # 缺的是静态文件，不能回落成 index.html
        return FileResponse(index, headers={"Cache-Control": "no-cache"})


def create_app(cfg: Config | None = None, *, start_workers: bool = True,
               configure_logging: bool = True) -> FastAPI:
    cfg = cfg or load_config()

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        if configure_logging:
            setup_logging(cfg.log_dir)
        db = Database(cfg.data_dir / "studio.db")
        db.upgrade()
        bus = EventBus()
        bus.bind_loop(asyncio.get_running_loop())
        manager = JobManager(db, HANDLERS, bus)
        services = build_services(cfg, db, manager)
        manager.services = services
        manager.recover()
        app.state.cfg, app.state.services = cfg, services
        app.state.manager, app.state.bus = manager, bus
        if start_workers:
            manager.start()
        try:
            yield
        finally:
            manager.stop()
            db.engine.dispose()

    app = FastAPI(title="AI Studio", lifespan=lifespan)
    install_error_handlers(app)
    install_local_guards(app)
    for r in ROUTERS:
        app.include_router(r)
    install_frontend(app, cfg.frontend_dist)
    return app


def run() -> None:
    cfg = load_config()
    uvicorn.run(create_app(cfg), host=cfg.server.host, port=cfg.server.port, log_level="info")
```

```ts
import { vi } from 'vitest';

export interface FetchCall {
  method: string;
  url: string;
  body: unknown;
  headers: Record<string, string>;
}

export function json(data: unknown, status = 200): Response {
  return new Response(JSON.stringify(data), {
    status,
    headers: { 'Content-Type': 'application/json' },
  });
}

/**
 * 用一张「方法 路径」→ 返回值 的表替换全局 fetch，返回调用记录。
 * 路径先按带查询串精确匹配，再按去掉查询串匹配；值可以是数据、Response，或 (call) => 数据 | Response。
 */
export function installFetch(routes: Record<string, unknown>): FetchCall[] {
  const calls: FetchCall[] = [];
  const impl = async (input: RequestInfo | URL, init?: RequestInit): Promise<Response> => {
    const url =
      typeof input === 'string' ? input : input instanceof URL ? input.toString() : input.url;
    const method = (init?.method ?? 'GET').toUpperCase();
    const raw = init?.body;
    const call: FetchCall = {
      method,
      url,
      body: typeof raw === 'string' ? JSON.parse(raw) : undefined,
      headers: (init?.headers ?? {}) as Record<string, string>,
    };
    calls.push(call);
    const path = url.replace(/^https?:\/\/[^/]+/, '');
    const key = [`${method} ${path}`, `${method} ${path.split('?')[0]}`].find((k) => k in routes);
    if (key === undefined) return json({ detail: `测试里没有模拟 ${method} ${path}` }, 404);
    const route = routes[key];
    const value =
      typeof route === 'function' ? await (route as (c: FetchCall) => unknown)(call) : route;
    return value instanceof Response ? value : json(value ?? null);
  };
  vi.stubGlobal('fetch', vi.fn(impl));
  return calls;
}
```

```tsx
export function newQueryClient(): QueryClient {
  return new QueryClient({
    defaultOptions: { queries: { retry: false, gcTime: Infinity }, mutations: { retry: false } },
  });
}

function LocationProbe() {
  const loc = useLocation();
  return <div data-testid="location">{loc.pathname + loc.search}</div>;
}

interface RenderOptions {
  route?: string;
  path?: string;
  qc?: QueryClient;
}

/** 在 MemoryRouter + QueryClientProvider 里渲染；ui 挂在 path 上，当前地址显示在 data-testid="location"。 */
export function renderAt(ui: ReactElement, { route = '/', path = '*', qc = newQueryClient() }: RenderOptions = {}) {
  const result = render(
    <QueryClientProvider client={qc}>
      <MemoryRouter initialEntries={[route]}>
        <Routes>
          <Route path={path} element={ui} />
          {path !== '*' && <Route path="*" element={null} />}
        </Routes>
        <LocationProbe />
      </MemoryRouter>
    </QueryClientProvider>,
  );
  return { qc, ...result };
}
```

```ts
// 调用后端 HTTP API 的薄封装：统一把失败变成带中文说明和状态码的 ApiError。

export class ApiError extends Error {
  readonly status: number;

  constructor(status: number, message: string) {
    super(message);
    this.name = 'ApiError';
    this.status = status;
  }
}

/** URL 路径里的 slug 一律编码（slug 可以是中文）。 */
export const enc = encodeURIComponent;

interface ValidationItem {
  loc?: unknown[];
  msg?: string;
}

/** 后端 detail 可能是字符串（我们自己的错误）或 FastAPI 的 422 校验列表。 */
export function detailText(detail: unknown): string {
  if (typeof detail === 'string') return detail;
  if (Array.isArray(detail)) {
    return detail
      .map((d: ValidationItem) => {
        const loc = Array.isArray(d?.loc) ? d.loc.filter((x) => x !== 'body').join('.') : '';
        const msg = d?.msg ?? JSON.stringify(d);
        return loc ? `${loc}：${msg}` : msg;
      })
      .join('；');
  }
  return JSON.stringify(detail);
}

export async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  let res: Response;
  try {
    res = await fetch(path, {
      method,
      headers: body === undefined ? undefined : { 'Content-Type': 'application/json' },
      body: body === undefined ? undefined : JSON.stringify(body),
    });
  } catch {
    throw new ApiError(0, '连不上工作台服务，确认 uv run studio-server 正在运行');
  }
  const text = await res.text();
  let data: unknown = null;
  if (text) {
    try {
      data = JSON.parse(text);
    } catch {
      data = text;
    }
  }
  if (!res.ok) {
    const detail =
      data !== null && typeof data === 'object' && 'detail' in data
        ? (data as { detail: unknown }).detail
        : data || res.statusText;
    throw new ApiError(res.status, `${detailText(detail)}（HTTP ${res.status}）`);
  }
  return data as T;
}

export const api = {
  get: <T>(path: string) => request<T>('GET', path),
  post: <T>(path: string, body: unknown = {}) => request<T>('POST', path, body),
  patch: <T>(path: string, body: unknown) => request<T>('PATCH', path, body),
  put: <T>(path: string, body: unknown) => request<T>('PUT', path, body),
  del: (path: string) => request<null>('DELETE', path),
};

export function errorText(e: unknown): string {
  return e instanceof Error ? e.message : String(e);
}
```

### Task 7: WebSocket 事件 hook

连接 `/api/ws`，把事件变成两类效果：进度和连接状态进 reducer（任务条要用）；其余一律变成查询失效（任务、队列、剧集、成片……），由 TanStack Query 重新拉取。断线 2 秒后重连；重连成功时全部查询失效，补上断线期间漏掉的事件。

后端推送的事件形状（`backend/queue/manager.py`、`backend/queue/context.py`、`backend/app/routes/ws.py`）：
- `{"type": "queue", "paused": bool, "counts": {"queued", "running", "waiting_input"}, "current_family": str | null}`（连上时先推一条；暂停/恢复时再推）
- `{"type": "job", "job": job_to_dict(...)}`（提交、开始、结束、等待输入、取消时）
- `{"type": "log", "job_id": int, "line": str}`
- `{"type": "progress", "job_id": int, "value": int, "max": int}`

```ts
// /api/ws 推来的事件，以及它们对界面的两种效果：reducer 里的进度/连接状态、要失效的查询。
import type { QueryKey } from '@tanstack/react-query';
import type { Job, JobStatus, QueueState } from '../api/types';

export type WsEvent =
  | ({ type: 'queue' } & QueueState)
  | { type: 'job'; job: Job }
  | { type: 'log'; job_id: number; line: string }
  | { type: 'progress'; job_id: number; value: number; max: number };

export interface Progress {
  value: number;
  max: number;
}

export interface EventsState {
  connected: boolean;
  progress: Record<number, Progress>;
}

export type EventsAction = WsEvent | { type: 'connected' } | { type: 'disconnected' };

export const initialEvents: EventsState = { connected: false, progress: {} };

export function eventsReducer(state: EventsState, action: EventsAction): EventsState {
  switch (action.type) {
    case 'connected':
      return state.connected ? state : { ...state, connected: true };
    case 'disconnected':
      return state.connected ? { ...state, connected: false } : state;
    case 'progress':
      return { ...state, progress: { ...state.progress, [action.job_id]: { value: action.value, max: action.max } } };
    case 'job': {
      const id = action.job.id;
      if (action.job.status === 'running' || !(id in state.progress)) return state;
      const progress = { ...state.progress };
      delete progress[id];
      return { ...state, progress };
    }
    default:
      return state;
  }
}

/** 任务停下来（完成、失败、取消、等人工输入）时，它可能改了剧集、镜头、候选、成片。 */
const SETTLED: JobStatus[] = ['done', 'failed', 'canceled', 'waiting_input'];
const LLM_TYPES = ['script', 'storyboard'];

export function invalidationsFor(ev: WsEvent): QueryKey[] {
  switch (ev.type) {
    case 'job': {
      const out: QueryKey[] = [['jobs'], ['queue'], ['job', ev.job.id]];
      if (SETTLED.includes(ev.job.status)) {
        out.push(['episode'], ['exports']);
        if (LLM_TYPES.includes(ev.job.type)) out.push(['episodes'], ['characters'], ['locations'], ['style']);
      }
      return out;
    }
    case 'log':
      return [['job', ev.job_id]];
    default:
      return [];
  }
}
```

```ts
import { useQueryClient } from '@tanstack/react-query';
import { useEffect, useReducer } from 'react';
import { keys } from '../api/queries';
import type { QueueState } from '../api/types';
import { type EventsState, type WsEvent, eventsReducer, initialEvents, invalidationsFor } from './events';

export type WebSocketCtor = new (url: string) => WebSocket;

export interface StudioEventsOptions {
  url?: string;
  WebSocketImpl?: WebSocketCtor;
  retryMs?: number;
}

/** 开发态经 Vite 代理、生产态直连后端，都是当前页面同一个 host。 */
export function defaultWsUrl(): string {
  const { protocol, host } = window.location;
  return `${protocol === 'https:' ? 'wss' : 'ws'}://${host}/api/ws`;
}

export function useStudioEvents({ url, WebSocketImpl, retryMs = 2000 }: StudioEventsOptions = {}): EventsState {
  const qc = useQueryClient();
  const [state, dispatch] = useReducer(eventsReducer, initialEvents);

  useEffect(() => {
    const Impl: WebSocketCtor = WebSocketImpl ?? WebSocket;
    const target = url ?? defaultWsUrl();
    let ws: WebSocket | null = null;
    let timer: ReturnType<typeof setTimeout> | undefined;
    let stopped = false;
    let dropped = false;

    const connect = () => {
      ws = new Impl(target);
      ws.onopen = () => {
        dispatch({ type: 'connected' });
        // 断线期间的事件已经丢了：重连成功后把所有查询重新拉一遍
        if (dropped) void qc.invalidateQueries();
      };
      ws.onmessage = (m: MessageEvent) => {
        let ev: WsEvent;
        try {
          ev = JSON.parse(String(m.data)) as WsEvent;
        } catch {
          return;
        }
        dispatch(ev);
        if (ev.type === 'queue') {
          qc.setQueryData<QueueState>(keys.queue, {
            paused: ev.paused,
            counts: ev.counts,
            current_family: ev.current_family,
          });
        }
        for (const queryKey of invalidationsFor(ev)) void qc.invalidateQueries({ queryKey });
      };
      ws.onclose = () => {
        dispatch({ type: 'disconnected' });
        if (stopped) return;
        dropped = true;
        timer = setTimeout(connect, retryMs);
      };
    };

    connect();
    return () => {
      stopped = true;
      if (timer) clearTimeout(timer);
      if (ws) {
        ws.onclose = null;
        ws.close();
      }
    };
  }, [qc, url, WebSocketImpl, retryMs]);

  return state;
}
```

```ts
import type { JobStatus } from './api/types';

export const JOB_TYPE_LABEL: Record<string, string> = {
  script: '剧本',
  storyboard: '分镜',
  'image.keyframe': '首帧',
  'video.shot': '视频',
  'export.episode': '合成导出',
};

export const JOB_STATUS_LABEL: Record<JobStatus, string> = {
  queued: '排队中',
  running: '运行中',
  waiting_input: '等待输入',
  done: '完成',
  failed: '失败',
  canceled: '已取消',
};

export const EPISODE_STATUS_LABEL: Record<string, string> = {
  draft: '草稿',
  scripted: '已出剧本',
  storyboarded: '已分镜',
  exported: '已导出',
};

export const ACTIVE_STATUSES: JobStatus[] = ['queued', 'running', 'waiting_input'];

export function jobTypeLabel(t: string): string {
  return JOB_TYPE_LABEL[t] ?? t;
}

export function jobStatusLabel(s: string): string {
  return (JOB_STATUS_LABEL as Record<string, string>)[s] ?? s;
}

/** 后端有的时间带 Z（任务），有的不带（候选、成片，存的是 UTC）：不带时区的一律按 UTC。 */
function parse(iso: string): Date {
  return new Date(/[zZ]$|[+-]\d\d:\d\d$/.test(iso) ? iso : `${iso}Z`);
}

export function fmtTime(iso: string | null | undefined): string {
  if (!iso) return '—';
  const d = parse(iso);
  return Number.isNaN(d.getTime()) ? iso : d.toLocaleString('zh-CN', { hour12: false });
}

export function fmtDuration(
  start: string | null | undefined,
  end: string | null | undefined,
  now: number = Date.now(),
): string {
  if (!start) return '—';
  const ms = (end ? parse(end).getTime() : now) - parse(start).getTime();
  if (!(ms >= 0)) return '—';
  const s = Math.round(ms / 1000);
  return s < 60 ? `${s} 秒` : `${Math.floor(s / 60)} 分 ${s % 60} 秒`;
}
```

```tsx
import { type FormEvent, useEffect, useState } from 'react';

export interface FieldOption {
  value: string;
  label: string;
}

export interface FieldSpec {
  name: string;
  label: string;
  kind?: 'text' | 'textarea' | 'number' | 'select';
  rows?: number;
  options?: FieldOption[];
  step?: string;
}

export type FieldValues = Record<string, string>;

export interface EditableFieldsProps {
  fields: FieldSpec[];
  initial: FieldValues;
  onSave: (values: FieldValues, changed: FieldValues) => void;
  saving?: boolean;
  error?: string | null;
  saveLabel?: string;
}

export function changedValues(values: FieldValues, initial: FieldValues): FieldValues {
  const out: FieldValues = {};
  for (const k of Object.keys(values)) {
    if (values[k] !== initial[k]) out[k] = values[k];
  }
  return out;
}

export function EditableFields({ fields, initial, onSave, saving = false, error = null, saveLabel = '保存' }: EditableFieldsProps) {
  // 用内容做比较，而不是对象身份：WebSocket 触发的重新拉取若内容没变，不会冲掉正在编辑的内容
  const initialKey = JSON.stringify(initial);
  const [values, setValues] = useState<FieldValues>(initial);
  useEffect(() => {
    setValues(JSON.parse(initialKey) as FieldValues);
  }, [initialKey]);

  const base = JSON.parse(initialKey) as FieldValues;
  const changed = changedValues(values, base);
  const dirty = Object.keys(changed).length > 0;
  const set = (name: string, v: string) => setValues((prev) => ({ ...prev, [name]: v }));
  const submit = (e: FormEvent) => {
    e.preventDefault();
    if (dirty) onSave(values, changed);
  };

  return (
    <form className="fields" onSubmit={submit}>
      {fields.map((f) => (
        <label key={f.name} className="field">
          <span>{f.label}</span>
          {f.kind === 'textarea' ? (
            <textarea rows={f.rows ?? 4} value={values[f.name] ?? ''} onChange={(e) => set(f.name, e.target.value)} />
          ) : f.kind === 'select' ? (
            <select value={values[f.name] ?? ''} onChange={(e) => set(f.name, e.target.value)}>
              {(f.options ?? []).map((o) => (
                <option key={o.value} value={o.value}>
                  {o.label}
                </option>
              ))}
            </select>
          ) : (
            <input
              type={f.kind === 'number' ? 'number' : 'text'}
              step={f.step}
              value={values[f.name] ?? ''}
              onChange={(e) => set(f.name, e.target.value)}
            />
          )}
        </label>
      ))}
      <div className="row">
        <button type="submit" disabled={!dirty || saving}>
          {saving ? '保存中…' : saveLabel}
        </button>
        {dirty && <span className="muted">有未保存的修改</span>}
        {error && <span className="error">{error}</span>}
      </div>
    </form>
  );
}
```

```ts
import type { Candidate, ShotDetail, Slot } from '../../api/types';

export const SLOT_LABEL: Record<string, string> = { first_frame: '首帧', end_frame: '尾帧', video: '视频' };

export type SlotMark = 'none' | 'ok' | 'stale';

export function slotOf(shot: ShotDetail, kind: string): Slot | undefined {
  return shot.slots.find((s) => s.kind === kind);
}

export function selectedOf(slot: Slot | undefined): Candidate | undefined {
  if (!slot || slot.selected_candidate_id == null) return undefined;
  return slot.candidates.find((c) => c.id === slot.selected_candidate_id);
}

/** 过期只对"选定的那个候选"有意义：后端按当前输入哈希比对后给出 slot.stale。 */
export function slotMark(slot: Slot | undefined): SlotMark {
  if (!slot || !selectedOf(slot)) return 'none';
  return slot.stale ? 'stale' : 'ok';
}

/** 把 id 和相邻的交换位置；越界返回 null。 */
export function moveId(ids: number[], id: number, delta: -1 | 1): number[] | null {
  const i = ids.indexOf(id);
  const j = i + delta;
  if (i < 0 || j < 0 || j >= ids.length) return null;
  const next = [...ids];
  [next[i], next[j]] = [next[j], next[i]];
  return next;
}
```

```tsx
/** 只把改过的字段转成 PATCH 体：时长转数字，引擎留空表示回到项目默认（null）。 */
export function toShotPatch(changed: FieldValues): ShotPatch {
  const out: ShotPatch = {};
  for (const [k, v] of Object.entries(changed)) {
    if (k === 'duration') out.duration = Number(v);
    else if (k === 'image_engine' || k === 'video_engine') out[k] = v === '' ? null : v;
    else if (k === 'transition_out') out.transition_out = v as Transition;
    else if ((TEXT_FIELDS as readonly string[]).includes(k)) out[k as (typeof TEXT_FIELDS)[number]] = v;
  }
  return out;
}
```

```tsx
export function DirectorPage() {
  const { slug = '', episodeId = '' } = useParams();
  const id = Number(episodeId);
  const [params, setParams] = useSearchParams();
  const ep = useEpisode(id);
  const exportsQ = useExports(id);
  const run = useRunStage(id);
  const reorder = useReorderShots(id);
  const split = useSplitShot(id);
  const del = useDeleteShot(id);
  const create = useCreateShot(id);
  const [selected, setSelected] = useState<Set<number>>(() => new Set());
  const [count, setCount] = useState(1);
  const [force, setForce] = useState(false);
  const [notice, setNotice] = useState<string | null>(null);

  if (ep.isLoading) return <p className="muted">加载中…</p>;
  if (ep.error || !ep.data) return <p className="error">{ep.error ? errorText(ep.error) : '找不到这一集'}</p>;
  const e = ep.data;
  const shots = e.shots;
  const openId = Number(params.get('shot')) || null;
  const openShot = shots.find((s) => s.id === openId) ?? null;
  const busy = reorder.isPending || split.isPending || del.isPending || create.isPending;
  const selIds = shots.filter((s) => selected.has(s.id)).map((s) => s.id);
  const scope = selIds.length > 0 ? `选中 ${selIds.length} 镜` : '全部';
  const total = shots.reduce((a, s) => a + s.duration, 0);

  const report = (p: Promise<unknown>, ok: string) => {
    p.then(
      () => setNotice(ok),
      (err: unknown) => setNotice(errorText(err)),
    );
  };

  // 镜头用 id 而不是 S01 这类编号：编号在排序、拆分、删除后会变
  const generate = (stage: GenStage | 'export', ids: number[] = []) => {
    const body: RunIn = { stage, candidates: count, force };
    if (ids.length > 0) body.shots = ids.map(String);
    run.mutate(body, {
      onSuccess: (r) => setNotice(`已提交 ${r.job_ids.length} 个任务（#${r.job_ids.join(', #')}），进度见顶部任务条`),
      onError: (err) => setNotice(errorText(err)),
    });
  };

  const toggle = (shotId: number) =>
    setSelected((prev) => {
      const next = new Set(prev);
      if (next.has(shotId)) next.delete(shotId);
      else next.add(shotId);
      return next;
    });
  const toggleAll = () =>
    setSelected((prev) =>
      shots.every((s) => prev.has(s.id)) ? new Set<number>() : new Set<number>(shots.map((s) => s.id)),
    );

  const move = (shotId: number, delta: -1 | 1) => {
    const next = moveId(shots.map((s) => s.id), shotId, delta);
    if (next) report(reorder.mutateAsync(next), '已调整顺序');
  };

  const remove = (shotId: number) => {
    const s = shots.find((x) => x.id === shotId);
    if (!s || !window.confirm(`删除镜头 ${s.code}？它的候选会一起删掉（媒体文件留在磁盘上）。`)) return;
    setSelected((prev) => {
      const next = new Set(prev);
      next.delete(shotId);
      return next;
    });
    if (openId === shotId) setParams({});
    report(del.mutateAsync(shotId), `已删除 ${s.code}`);
  };

  return (
    <div className="page">
      <header className="page-head">
        <h2>
          导演台 · 第 {e.number} 集 {e.title}
        </h2>
        <span className="muted">
          {shots.length} 个镜头，共 {total.toFixed(1)} 秒
        </span>
        <Link to={`/projects/${enc(slug)}/episodes/${id}/script`}>回剧本页</Link>
      </header>

      <div className="toolbar">
        <label>
          候选数{' '}
          <select aria-label="候选数" value={count} onChange={(ev) => setCount(Number(ev.target.value))}>
            {[1, 2, 3, 4].map((n) => (

                {n}
              </option>
            ))}
          </select>
        </label>

          <input type="checkbox" aria-label="强制重跑" checked={force} onChange={(ev) => setForce(ev.target.checked)} /> 强制重跑
        </label>
        <button type="button" className="primary" disabled={shots.length === 0 || run.isPending} onClick={() => generate('keyframes', selIds)}>

        </button>
        <button type="button" className="primary" disabled={shots.length === 0 || run.isPending} onClick={() => generate('videos', selIds)}>
          生成视频（{scope}）
        </button>
        <button type="button" disabled={busy} onClick={() => report(create.mutateAsync({}), '已在末尾新增镜头')}>
          新增镜头
        </button>
        <button type="button" disabled={shots.length === 0 || run.isPending} onClick={() => generate('export')}>
          合成导出
        </button>
      </div>
      {notice && (
        <p className="notice" role="status">
          {notice}
        </p>

        </p>
      ) : (

          shots={shots}
          selected={selected}
          busy={busy}

          onToggleAll={toggleAll}

          onMove={move}
          onSplit={(shotId) => report(split.mutateAsync(shotId), '已拆分')}

          episodeId={id}

}
```

```tsx
function PromptBlock({ label, text }: { label: string; text: string }) {
  const [copied, setCopied] = useState(false);
  const copy = async () => {
    try {
      await navigator.clipboard.writeText(text);
      setCopied(true);
    } catch {
      setCopied(false); // 剪贴板不可用时手动全选复制
    }
  };
  return (
    <div className="fields">
      <label className="field">
        <span>{label}</span>
        <textarea readOnly rows={8} value={text} />
      </label>
      <div className="row">
        <button type="button" onClick={() => void copy()}>
          复制
        </button>
        {copied && <span className="muted">已复制</span>}
      </div>
    </div>
  );
}

export interface ManualInputFormProps {
  job: Job;
  onSubmitted?: (job: Job) => void;
}

export function ManualInputForm({ job, onSubmitted }: ManualInputFormProps) {
  const input = useProvideInput();
  const [text, setText] = useState('');
  const req = job.result?.input_request;
  if (!req) return null;

  const submit = () =>
    input.mutate(
      { id: job.id, text },
      {
        onSuccess: (j) => {
          setText('');
          onSubmitted?.(j);
        },
      },
    );

  return (
    <section className="manual">
      <h4>
        等待人工输入：<code data-testid="input-key">{req.key}</code>
      </h4>
      <p className="muted">
        这一步配置成了 manual：把下面两段提示词交给任意模型（或另一个 Claude 会话），把它输出的 JSON 原样粘贴到最下面，提交后任务会重新排队。
      </p>
      {req.error && <p className="error">上次粘贴的结果不合格：{req.error}</p>}
      <PromptBlock label="系统提示词（system）" text={req.system} />
      <PromptBlock label="用户提示词（user）" text={req.user} />
      <label className="field">
        <span>模型输出</span>
        <textarea rows={12} value={text} onChange={(e) => setText(e.target.value)} placeholder='{"...": ...}' />
      </label>
      <div className="row">
        <button type="button" className="primary" disabled={!text.trim() || input.isPending} onClick={submit}>
          提交结果
        </button>
      </div>
      {input.error && <p className="error">{errorText(input.error)}</p>}
    </section>
  );
}
```

```tsx
import { errorText } from '../api/client';
import { useCancelJob, useJob, useJobs, useRetryJob } from '../api/queries';
import { ACTIVE_STATUSES, fmtDuration, fmtTime, jobStatusLabel, jobTypeLabel } from '../format';
import { ManualInputForm } from './jobs/ManualInputForm';

const STATUS_OPTIONS = [
  { value: '', label: '全部' },
  { value: 'waiting_input', label: '等待输入' },
  { value: 'running', label: '运行中' },
  { value: 'queued', label: '排队中' },
  { value: 'failed', label: '失败' },
  { value: 'done', label: '完成' },
  { value: 'canceled', label: '已取消' },
];

function JobDetail({ id, onRetried }: { id: number; onRetried: (newId: number) => void }) {
  const job = useJob(id);
  const cancel = useCancelJob();
  const retry = useRetryJob();
  const logRef = useRef<HTMLPreElement>(null);
  const log = job.data?.log ?? '';
  useEffect(() => {
    const el = logRef.current;
    if (el) el.scrollTop = el.scrollHeight;
  }, [log]);

  if (job.isLoading) return <section className="panel muted">加载中…</section>;
  if (job.error || !job.data) {
    return <section className="panel error">{job.error ? errorText(job.error) : `找不到任务 ${id}`}</section>;
  }
  const j = job.data;
  const req = j.result?.input_request;
  const active = ACTIVE_STATUSES.includes(j.status);

  return (
    <section className="panel">
      <div className="page-head">
        <h3>
          任务 #{j.id} · {jobTypeLabel(j.type)}
        </h3>
        <span data-testid="job-status" className={`job-${j.status}`}>
          {jobStatusLabel(j.status)}
        </span>
      </div>
      <p className="muted">
        创建 {fmtTime(j.created_at)} · 开始 {fmtTime(j.started_at)} · 结束 {fmtTime(j.finished_at)} · 耗时{' '}
        {fmtDuration(j.started_at, j.finished_at)}
        {j.model_family ? ` · 模型族 ${j.model_family}` : ''}
        {j.depends_on.length > 0 ? ` · 依赖 #${j.depends_on.join(', #')}` : ''}
      </p>
      <div className="row">
        {active && (
          <button type="button" disabled={cancel.isPending} onClick={() => cancel.mutate(j.id)}>
            取消
          </button>
        )}
        {(j.status === 'failed' || j.status === 'canceled') && (
          <button
            type="button"
            className="primary"
            disabled={retry.isPending}
            onClick={() => retry.mutate(j.id, { onSuccess: (r) => onRetried(r.job_id) })}
          >
            重试
          </button>
        )}
      </div>
      {cancel.data && !cancel.data.ok && <p className="warn">没能取消（任务可能已经结束）</p>}
      {(cancel.error || retry.error) && <p className="error">{errorText(cancel.error ?? retry.error)}</p>}
      {j.error && (
        <>
          <h4>错误</h4>
          <pre className="error">{j.error}</pre>
        </>
      )}

      <h4>日志</h4>

        <summary>参数（payload）</summary>
        <pre>{JSON.stringify(j.payload, null, 2)}</pre>
      </details>

        <details>
          <summary>结果</summary>
          <pre>{JSON.stringify(j.result, null, 2)}</pre>
        </details>
      )}
    </section>
  );
}

export function JobsPage() {
  const [params, setParams] = useSearchParams();
  const status = params.get('status') ?? '';
  const selectedId = Number(params.get('job')) || null;
  const jobs = useJobs(status);

  const update = (patch: Record<string, string | null>) => {
    const next = new URLSearchParams(params);
    for (const [k, v] of Object.entries(patch)) {
      if (v === null || v === '') next.delete(k);
      else next.set(k, v);
    }
    setParams(next);
  };

  return (
    <div className="split jobs">
      <section className="panel">
        <div className="page-head">
          <h2>任务</h2>
          <select aria-label="状态筛选" value={status} onChange={(e) => update({ status: e.target.value })}>
            {STATUS_OPTIONS.map((o) => (
              <option key={o.value} value={o.value}>
                {o.label}
              </option>
            ))}
          </select>
        </div>
        {jobs.error && <p className="error">{errorText(jobs.error)}</p>}
        {jobs.data && jobs.data.length === 0 && <p className="muted">没有任务。</p>}
        <table className="table">
          <thead>
            <tr>
              <th>#</th>
              <th>类型</th>
              <th>状态</th>
              <th>耗时</th>
            </tr>

      )}
    </div>
  );
}
```

```tsx
import { errorText } from '../api/client';
import { useConfig, useDoctor, useEngines } from '../api/queries';
import type { DoctorCheck, EngineRow } from '../api/types';

const ICON: Record<DoctorCheck['status'], string> = { ok: '√', warn: '!', fail: '×' };

function summary(rows: DoctorCheck[]): string {
  const fails = rows.filter((r) => r.status === 'fail').length;
  const warns = rows.filter((r) => r.status === 'warn').length;
  if (!fails && !warns) return '全部通过';
  return [fails ? `${fails} 项失败` : '', warns ? `${warns} 项警告` : ''].filter(Boolean).join('，');
}

function capsText(kind: 'image' | 'video', e: EngineRow): string {
  const c = e.caps;
  const sizes = Object.keys((c.sizes as Record<string, unknown> | undefined) ?? {}).join(' / ');
  if (kind === 'video') {
    return `${c.has_audio ? '有声' : '无声'} · ${c.fps} fps · 默认 ${c.default_seconds} 秒 / 最长 ${c.max_seconds} 秒 · 参考图上限 ${c.max_refs}`;
  }
  return `参考图上限 ${c.max_refs} · ${c.supports_negative ? '支持' : '不支持'}负面提示词 · 画幅 ${sizes}`;
}

export function SettingsPage() {
  const doctor = useDoctor();
  const engines = useEngines();
  const config = useConfig();
  const rows = doctor.data ?? [];
  const engineRows: [string, 'image' | 'video', EngineRow][] = [
    ...(engines.data?.image ?? []).map((e): [string, 'image', EngineRow] => ['图像', 'image', e]),
    ...(engines.data?.video ?? []).map((e): [string, 'video', EngineRow] => ['视频', 'video', e]),
  ];

  return (
    <div className="page">
      <section className="panel">
        <div className="page-head">
          <h2>环境检查（doctor）</h2>
          <button type="button" disabled={doctor.isFetching} onClick={() => void doctor.refetch()}>
            {doctor.isFetching ? '检查中…（最长十几秒）' : '重新检查'}
          </button>
        </div>
        {doctor.error && <p className="error">{errorText(doctor.error)}</p>}
        {doctor.data && <p data-testid="doctor-summary">{summary(rows)}</p>}
        <table className="table">
          <thead>
            <tr>
              <th />
              <th>分组</th>
              <th>项目</th>
              <th>详情</th>
            </tr>
          </thead>
          <tbody>
            {rows.map((r, i) => (
              <tr key={i}>
                <td className={`status-${r.status}`}>{ICON[r.status]}</td>
                <td>{r.group}</td>
                <td>{r.name}</td>
                <td>{r.detail}</td>
              </tr>
            ))}
          </tbody>
        </table>
      </section>

        <table className="table">

              <th>能力</th>
            </tr>
          </thead>
          <tbody>
            {engineRows.map(([label, kind, e]) => (
              <tr key={e.name}>
                <td>{e.name}</td>
                <td>{label}</td>
                <td>{e.family}</td>
                <td>{capsText(kind, e)}</td>
              </tr>
            ))}
          </tbody>
```

```ts
async function waitQueueIdle(page: Page, slug: string) {

    .poll(
```
