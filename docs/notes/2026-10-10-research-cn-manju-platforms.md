# 国内 AI 漫剧 / 短剧创作平台：工作流与交互调研（2025–2026）

调研日期：2026-10-10。资料来自官方新闻稿、媒体测评（36氪/钛媒体/人人都是产品经理/量子位/智东西/爱范儿）、教程站与 GitHub。
可信度说明：知乎、CSDN 部分页面 403/521 无法直读，相关结论只引用搜索摘要的，标【摘要】；无法找到一手出处的标【未核实】。我没有登录任何产品亲测，所有界面描述都来自第三方文字，按钮名以原文引用为准。

---

## 0. 一页结论

1. **行业已经从“分页面工具”收敛到两种形态**：
   - **“对话 + 阶段性确认”的 Agent 流水线**（小云雀短剧 Agent、Seko、海螺 Media Agent、纳逗Pro、天工“智能分镜模式”）：用户给一句话/剧本，Agent 依次产出“策划/故事蓝图 → 角色/场景 → 分镜 → 视频”，每个阶段停下来让用户确认或用对话修改。
   - **“无限画布 + 节点 + 资产卡”**（即梦 Octo、可灵灵动画布、LibTV、天工 SkyProduction、RHTV、Toonflow、TapNow）：剧本、角色、分镜、视频都是画布上的节点，改哪个节点就重跑哪个节点。
   - 两者正在合流：小云雀把整剧放在“同一张画布”里，Seko 有“画布编辑”，LibTV 的 Agent（龙虾/OpenClaw）跑完后把“项目画布链接”交还给用户。
2. **角色一致性的通用做法是“资产卡 + @引用”**：即梦“角色管理→@角色名”、Octo 资产卡（星标主参考）、Vidu `@主体`、可灵“主体（element）”、白日梦“@XX角色 敲门”。资产只建一次，镜头里用 @ 引用，不在每个镜头表单里重复填写。
3. **重新生成的主流粒度是“单镜（片段重拍）”**；整段重写剧本则靠“阶段确认 + 回到对应节点”。**我没有找到任何国内产品提供“剧本/分镜 diff 对比”或“重生成时保留手改字段”的明确功能**。这一块是空白，也是我们可以做出差异的地方（见第 4 节）。
4. **反面教材很集中**：纳逗Pro“下达指令后无法中止、修改”、积分不透明、生成顺序随机；海螺 Agent 早期“不可编辑和暂停修改”；万兴剧厂/小云雀“抽卡赌命”，每抽一次都要扣积分。

## 1. 逐产品分析

格式：①核心单位 ②想法→首段视频的步骤/页面 ③角色一致性 ④重生成/多版本 ⑤进度/排队/成本 ⑥自动 vs 用户决定 ⑦可抄的 / 反面的

### 1.1 即梦 AI（Dreamina，字节）

**A. 传统生成页 + 故事创作 + 智能画布**
- ① 单条生成任务（图/视频），外加“故事创作”模式（分镜 + 时间轨道）和“智能画布”（局部重绘/扩图/消除/抠图）。来源：[塔猴教程](https://www.tahou.com/article/217656615786854405)【摘要】、[ai-bot 即梦](https://ai-bot.cn/sites/6353.html)【摘要】
- ② 教程推荐的“精细短剧”是七步：剧本分镜拆解→创建固定角色档案→逐镜生静态图→图生视频→AI 配音→剪映合成→导出（[新浪教程](https://www.sina.cn/news/detail/5314878408757801.html)）。“极速一键短片”则是在 App 里进“剧情短片 Agent”，粘贴整套分镜，上传角色/场景参考图后生成，约 3–8 分钟（同上）。
- ③ “即梦首页→【角色管理】→新建角色”，“系统生成专属引用标识，后续所有镜头直接@角色名调用”（同上）。参考图拆成“内容、风格、结构、姿态四种参考”（[人人都是产品经理](https://www.woshipm.com/ai/6370967.html)）。
- ④ 单条任务可以多次生成；生成图片后“系统会智能预测下一步动作，主动推荐‘扩图’……或‘转视频’”（同上）。2025-08 上线“智能多帧”：10 张图生成 54 秒长镜头，每两帧之间可单独设时长和运镜提示词（[CSDN 摘要](https://adg.csdn.net/697073a3437a6b40336a4ee8.html)【摘要】）。
- ⑤ 免费用户“生成需排队”，VIP 有“专属加速通道（免排队）”；15 秒视频约 210 积分（[aitoollab](https://www.aitoollab.cn/articles/jimeng-ai-complete-guide-2026/)）；Seedance 2.0 Mini 5 秒 45 积分（[ai-indeed](https://www.ai-indeed.com/encyclopedia/23585.html)【摘要】）。
- ⑦ 可抄：**“下一步推荐”**，生成完直接给出“转视频/扩图”按钮，用户不必找入口。**“参考图按维度拆分”**（脸/风格/构图/姿态）。

**B. 即梦 Octo“小章鱼”（2026-04 内测）**
- ① 一张空白**无限画布**，“任何位置按 `/` 弹出对话框”；资产卡分风格/角色/环境/物体/自定义五类，每张卡有文字描述加参考图，可“星标”设为主参考。来源：[腾讯新闻](https://news.qq.com/rain/a/20260409A0716X00)、[网易](https://www.163.com/tech/article/KQ2SN3Q500098IEO.html)
- ② 灵感碰撞→资产建构→故事大纲→分镜脚本→视频生成→时间轴编排，全部在同一画布里完成。
- ③ 在对话框或生图节点里“打一个 @，选择资产名称”，系统“自动引入这些风格参考”。
- ④ 可以“在任何时候回到任何环节，跟任何一个节点展开对话”；同一分镜“多版本一起出”“一边扩数量，一边做筛选”。
- ⑤ 强调“边对话边生成的**异步并行**创作”：Octo 在生成分镜时，用户可以去构思下一段（[aiproducthub](https://aiproducthub.cn/sites/jimeng-ai-octo-vibe-create.html)【摘要】）。
- ⑥ Agent 会自动补全，例如“自动帮我把反派也补出来”；用户随时插话纠偏。
- ⑦ 可抄：**资产卡 + 星标主参考 + @ 引用**；**生成期间不锁界面**；**导出 XML 工程文件给 Premiere/FCP**。

### 1.2 可灵 AI（Kling，快手）

- ① 单次生成任务。另有**灵动画布**（节点式），用户可以“微调Prompt，并行的开跑好几个任务”，自带“整理画布”功能，最多 5 人协作（[腾讯云转载](https://cloud.tencent.com/developer/article/2548974)）。
- ② 可灵 3.0（2026-02-05）单次可生成“最多 6 个镜头”、15 秒以内的多镜头视频。“**智能分镜**”开关打开后由 AI 自己拆镜；“**自定义分镜**”让用户规划镜头数、每镜时长和每镜剧情（[人人都是产品经理实测](https://www.woshipm.com/ai/6341671.html)、[CSDN](https://www.csdn.net/article/2026-02-05/157772674)）。也就是说，一个**“镜头组”就是一次生成**，分镜表单被压缩进了单个生成面板。
- ③ “多图参考”（2025-01）：上传 1–4 张图，可**框选**图中的人物/物体/场景（[新浪](https://finance.sina.com.cn/tech/roll/2025-01-22/doc-inefvzcv6884574.shtml)）。3.0 的“主体”可以用图或视频创建，并能绑定**主体音色**（[CSDN 摘要](https://www.csdn.net/article/2026-02-05/157772674)）；API 层叫 `element_id`（[evolink 文档](https://evolink.ai/docs/cn/api-manual/video-series/kling/kling-custom-element.md)【摘要】）。“最多绑定 7 个主体”【摘要，来自[头条](https://www.toutiao.com/article/7629919136663011859/)，未核实】。
- ④ 主要是单任务重跑，或在画布上并行开多个分支。3.0 Omni 支持“改视频”（[搜狐](https://www.sohu.com/a/984656188_121124374)【摘要】）。
- ⑤ 积分叫“灵感值”，用户普遍抱怨贵【摘要】。我没查到可靠的排队 UI 细节【未核实】。
- ⑦ 可抄：**“智能分镜 / 自定义分镜”二选一开关**。默认让 AI 拆，要控制时再展开每镜时长和描述，这是很好的渐进披露。**主体绑定音色**：一个角色卡同时锁住脸和声音。

### 1.3 海螺 AI（MiniMax Hailuo）

- ① 单条生成 + **Media Agent / Video Agent**（对话式）。首页“Agent”入口下是模板（敦煌壁画、天降好物广告……），用户点“做同款”（[腾讯新闻体验](https://news.qq.com/rain/a/20250620A06ZFJ00)）。
- ② 选模板→上传图或写几个字→Agent 在右侧依次展示“分析图片信息→生成不同图片的提示词→生成视频剪辑”（同上）。“一键成片”和“分步创作”两种模式并存（[MiniMax 官方](https://www.minimax.cn/news/minimax-hailuo-23)）。
- ③ “主体参考”：上传一张图即可锁定主体（[玉米小站](https://www.yumiok.com/archives/2182.html)【摘要】）。
- ④ 早期测评原话：“**不可编辑和暂停修改的 Agent 不可进化**”（[腾讯新闻](https://news.qq.com/rain/a/20250620A06ZFJ00)）。官方规划后续“对成片链路上的任一 Part……在画布中与 Agent 一起调整细节”（[MiniMax](https://www.minimax.cn/news/minimax-hailuo-23)）。
- ⑤ 官方只提到 Hailuo 2.3 Fast“最高可为批量创作降低 50% 成本”。
- ⑦ 可抄：**右侧步骤流**，Agent 当前在做哪一步一目了然。反面：**Agent 跑起来就不能暂停、不能改**。

### 1.4 Vidu（生数科技）

- ① 单条生成，主打“参考生视频”。Q3 支持最多 7 个主体；Q4 Preview（2026-10-10）支持 15 张参考图 + 3 段音频（[17173](https://news.17173.com/content/10102026/100316907.shtml)【摘要】、[B站](https://www.bilibili.com/video/BV1915v6bEcs/)【摘要】）。
- ③ 角色创建器：上传“1 to 7 images of your character”，然后写提示词、选参数、生成（[Vidu 官方](https://www.vidu.com/tools/character-creator)）。
- ④/⑥ **主体社区**：除了角色，镜头、构图、表演、招式、场景、风格、氛围、特效共八类 200+ 预设都被做成可 `@` 调用的“主体”，可以叠加使用，例如“@镜头 + @氛围 + @特效 + 角色图”，“从‘抽卡模式’变为‘乐高模式’”（[爱范儿](https://www.ifanr.com/1653577)）。
- ⑤ 积分分订阅（30 天有效）、加购（2 年）、奖励（2 年），扣除顺序是订阅优先（[Vidu 定价](https://www.vidu.com/zh/pricing)【摘要】）。另有一键 MV 多 Agent（[腾讯新闻](https://news.qq.com/rain/a/20260114A03UAL00)）。
- ⑦ 可抄：**把运镜、景别、表演做成可 @ 的“预设卡”**，替代下拉框和长提示词。对我们来说就是用“镜头预设芯片”取代每镜一堆参数。

### 1.5 剪映 / CapCut：AI 文字成片（漫剧）

- ① 剪映专业版里的“成片助手”。产出物是**剪映多轨草稿**，时间线是最终单位。
- ② “一句话即可生成专业文字脚本，系统自动匹配画风、生成分镜并完成智能配音”，并且“可以将外部生成的短剧草稿一键导入剪映多轨道”继续精修（2026-06 内测）（[搜狐](https://www.sohu.com/a/1034821475_161795)、[腾讯新闻](https://news.qq.com/rain/a/20260610A07WVY00)）。
- ③ 13 款专属画风，可选 Seedream 4.1/4.5/5.0（同上）。角色锁定的具体 UI【未核实】。
- ⑤ “多档高性价比成片模型选择”：先选模型和价位，再生成。
- ⑦ 可抄：**AI 直出的终点是一个可编辑的时间线草稿**，而不是不可改的 mp4。

### 1.6 小云雀 短剧 Agent（剪映团队，2026-03 上线，后有 2.0）

- ① 以**项目/剧集**为单位，“同一张画布”上共存剧本、角色、场景、故事板（[人人都是产品经理](https://www.woshipm.com/ai/6460823.html)）。
- ② 上传剧本或一句话→“确认画风、画幅、旁白等基础需求”→自动“故事蓝图构建、角色设计、分镜生成”→成片（[科技日报](https://www.stdaily.com/web/gdxw/2026-03/20/content_488925.html)【摘要】）。产出物是“分集大纲、剧本正文、镜头拆分和故事板”，“用户在每个环节确认内容方向后继续推进，**避免整体推倒重来**”（[人人都是产品经理](https://www.woshipm.com/ai/6460823.html)）。
- ③ “全局角色管理”会扫描全剧本，分析角色的年龄、服饰、面部变化；平台有“7000 人多人种角色库”；“**角色与场景存成项目资产**，后续生成时就有了统一参考”；另有 3D 导演台调站位，结果“回流至主画布”（同上；[网易](https://www.163.com/dy/article/KOMVL6C605371CMM.html)）。
- ④ 可以“**逐个分镜修改提示词和角色引用**”，角色图不满意“可以随时替换”（[网易](https://www.163.com/dy/article/KOMVL6C605371CMM.html)【摘要】）。“某个镜头效果不合适，可以回到对应节点修改，不用把整集推倒重来”，系统自动处理首尾帧衔接（[人人都是产品经理](https://www.woshipm.com/ai/6460823.html)）。视频不满意就重抽，每次扣积分（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- ⑤ 包月 39 元送 1200 积分，Seedance 2.0 Fast 每秒 11 积分；**生图之前免费，从生图开始付费**（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- ⑦ 可抄：**阶段确认、局部回改**；**文本阶段免费，花钱的阶段才扣费**。反面：生成的角色图与剧本设定“两模两样”，用户“容易陷入‘算了’的无奈循环”（[钛媒体](https://www.tmtpost.com/7956912.html)）。

### 1.7 商汤 Seko（1.0 → 2.0）

- ① 对话驱动的项目，2.0 起支持“多剧集”，可连续创作 100 集；左侧“+”生成下一集（[智东西](https://zhidx.com/p/521333.html)）。
- ② 一句话→**策划文档**（策划摘要、美术风格、角色主体、场景概念、音乐风格、分镜剧本六部分），用户在右侧对话栏微调→“**先确认分镜静帧，再生成视频**”→“一键转视频”→导出。约 10 分钟出 3 场景 25 镜、约 90 秒（[智东西](https://zhidx.com/p/498269.html)）。
- ③ 自动生成主体列表和场景列表；SekoIDX 负责跨集跨镜的一致性；“人物妆造可随场景改变”（[量子位](https://www.qbitai.com/2025/12/360960.html)）。
- ④ 图片右上角的修改图标可调主体/场景；**画布编辑**支持消除、局部重绘、加元素、裁剪，“而不是被迫重新生成整张图”；提示词可重新编辑；可以“逐帧修改台词、配音和镜头结构”；“返回策划”继续做下一集（[人人都是产品经理](https://www.woshipm.com/ai/6306361.html)、[智东西](https://zhidx.com/p/498269.html)）。
- ⑦ 可抄：**策划文档是一页可读的“项目单”**，用户可以用对话改它；**静帧确认门**（先看全部静帧，确认后再花大钱转视频）；**局部重绘优先于整图重生成**。

### 1.8 万兴剧厂（万兴科技，ReelMate）

- ① 团队/项目，有企业级资产库，角色、场景、道具、音色可以跨项目复用（[搜狐](https://www.sohu.com/a/1026751281_122413884)）。
- ② 剧本链路分多阶段：“灵感规划、角色构建、世界观生成，到总纲设计、分集拆解”。AI 给出多种选择和建议，“而非直接替创作者做决定”（同上）。上传剧本后可以生成角色/场景/道具图并存为资产，系统自动拆镜头（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- ③ “同一角色在不同状态、不同场景甚至不同称呼下，都能准确识别”，音色可锁定进“团队音色库”【摘要】。
- ④ 可以换模型（Seedance 2.0 或可灵 O3）重生成单镜。厂商自称“分镜‘一抽可用’率 80%”（[搜狐](https://www.sohu.com/a/1026751281_122413884)）。测评则说失败后“调整提示词也很难过审”，像“赌命玄学”（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- ⑤ 100 元换 1000 积分，Seedance 2.0 最低 1.2 元/秒。
- ⑦ 可抄：**剧本分阶段，每阶段给 2–3 个候选让人挑**，而不是一次性吐出整本。**称呼别名识别**：同一角色的不同叫法自动归到同一资产。

### 1.9 天工短剧工作台 / SkyProduction（昆仑万维）

- ① 无限画布，节点连线表示引用关系（[爱范儿](https://www.ifanr.com/1678177)）。
- ② 两种模式：**传统分镜模式**（资产提取→文字分镜→分镜图→视频片段→合成剪辑）和**智能分镜模式**（剧本直接出视频片段，跳过分镜图）（[ai-bot](https://ai-bot.cn/skyproduction/)【摘要】）。
- ③ 资产提取 Agent 自动识别人物/场景/道具；多视图（正、侧、背、面部特写）“存入项目资产库永久锁定”；“**站位图锁定**”人物关系。
- ④ “**片段重拍**——哪一段不满意，就选哪一段重新生成”；“智能拉片”（[爱范儿](https://www.ifanr.com/1678177)）。用户可以“调试尺寸、单镜头生成数量、增删分镜”，可以选单镜时长和模型（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- ⑤ 按“项目、剧集和成员”查看消费明细；“**每项任务标记状态和 Task ID**，便于异常定位”；Seedance 2.5 720P 无参考低至 0.4 元/秒（[爱范儿](https://www.ifanr.com/1678177)）。
- ⑦ 可抄：**“快速模式 / 精细模式”双轨**；**每镜可设“生成数量”**（一次出 N 个候选）；**任务带状态和 ID**。

### 1.10 LibTV（LiblibAI 哩布）

- ① 无限画布，五种基础节点：文本、图片、视频、音频、脚本。节点连线，整套流程可“打组保存、一键重复执行”（[AIHub](https://www.aihub.cn/tools/libtv/)【摘要】）。
- ② 脚本节点有三种生成方式：剧本生成分镜脚本、视频参考生成分镜脚本、角色生成分镜脚本；点“**生成分镜**”批量出分镜图。内置工具包括多机位九宫格、剧情推演四宫格、25 宫格连贯分镜、角色三视图。宫格拆分流程：上传宫格图→「宫格拆分」→点选切片→「发送到生成器」→自动打组到新图片节点【摘要，来自 [fuyuan7/wuyi 教程](https://www.wuyi.wiki/post-2742.html)，原页 403】。
- ④ Agent（OpenClaw“龙虾”）全自动跑完约 5 分钟，返回“**成片链接和项目画布链接**”；不满意“可以手动对每个节点进行编辑，再让它重新生成”（[量子位](https://www.qbitai.com/2026/03/390320.html)）。
- ⑦ 可抄：**Agent 跑完的结果是一个可编辑的项目，而不是黑盒**；**宫格候选→挑一格→送去生成**（九宫格抽卡比逐张抽卡便宜）。

### 1.11 爱奇艺 纳逗Pro（反面教材集中地）

- “用户下达一项指令之后**无法中止、修改**，只能等全文跑完”；“**不透明的积分消耗**，没有明确提示生图、生视频具体消耗多少积分，积分不足则生成视频失败”；“生成视频顺序是**随机**的，用户无法简便通过时间线上的分镜图筛选镜头”（[钛媒体](https://www.tmtpost.com/7956912.html)）。
- 优点是分镜提示词“最贴近影视拍摄真实需求”，景别、构图、运镜都写得细（同上）。

### 1.12 白日梦 AI（光魔科技）

- ① 线性向导，5 步 5 页：编写故事→角色设定→选择分镜→编辑图片→预览视频（[映技派教程](https://www.yjpoo.com/article/3968.html)）。
- ② 故事页选画风，写标题和正文（≤2000 字），点【下一步】；角色页自动识别角色，点“设置形象”，可改名字/性别/配音；分镜页**左侧段落列表、右侧属性**（出镜角色、角色动作、场景描述），按“**@XX角色 敲门**”格式写好后点“**重新生成分镜**”；图片页有“生成图片”“**重绘当前画面**”“**换一批分镜**”；视频页“转动态”约 1 分钟，再选旁白、BGM、语速后发布（同上）。
- ③ 上传 5–8 张照片建角色库【摘要，[AIHub](https://www.aihub.cn/tools/video/bairimeng/)】。
- ⑦ 可抄：**左列表右属性的单页分镜编辑**；按钮语义清楚，“重绘当前画面”和“换一批分镜”区分了单镜和整批。反面：线性向导回退成本高（【未核实】，推断）。

### 1.13 讯飞绘镜（原星火绘镜，typemovie.art）

- 输入文字脚本→选 AI 短剧 / AI 预告片 / AI MV→生成内容和分镜（**默认 8 个分镜**）→生成视频（可选 7 种模型）→导出。参数有“创意种子”“动作幅度”，细节不满意用“**换一换**”（[ai-bot](https://ai-bot.cn/sites/12254.html)、[搜索摘要](https://moge.ai/zh/product/iflytek-typemovie)【摘要】）。AI 绘分镜“将脚本划分为合理视频的场景，再进一步将场景拆分为专业分镜，支持分镜自动补充”。
- ⑦ 可抄：**剧本→场景→分镜的两级拆分**。“默认 8 镜”这种固定数量限制了 30–90 秒的节奏，算反面。

## 2. 专题：剧本 / 分镜怎么“重新生成”

| 产品 | 整体重写剧本 | 分集 / 分场重写 | 单镜重生成 | 保留手改 | 对比 / 版本 |
|---|---|---|---|---|---|
| 小云雀 | 每阶段确认，“避免整体推倒重来” | 按集推进 | 逐镜改提示词和角色引用，重抽视频 | 回到节点改，其余不动（隐含保留） | 未见 |
| Seko | 策划文档 + 对话修改 | “返回策划”做下一集 | 改图标、画布局部重绘、改提示词 | 静帧确认后再转视频 | 未见 |
| 天工 | 两种模式 | — | **片段重拍**、增删分镜、单镜生成数量 | 只重拍选中段 | 任务带状态和 ID |
| 万兴剧厂 | 剧本多阶段，每阶段给多个候选 | 分集拆解 | 换模型重生成 | 未明确 | 未见 |
| LibTV | 脚本节点重跑 | 打组重复执行 | 节点重跑、宫格挑选 | 节点独立，天然保留 | 画布上并存多个分支 |
| 即梦 Octo | 对任意节点对话 | — | 同镜多版本并行 | 节点独立 | 多版本同屏筛选 |
| 白日梦 | 回到上一步 | — | “重新生成分镜”“重绘当前画面”“换一批分镜” | 未明确 | 未见 |
| 纳逗Pro | 黑箱，不可中止 | — | 难以筛选 | ✗ | ✗ |
| BigBanana | AI 续写 + 手改 | — | 重跑失败镜头、九宫格候选 | 未明确 | **提示词版本回滚** |
| 掘金教程（某平台） | 剧本助手在线改某一场措辞 | — | “片段重拍只重做这一镜，其余4镜保留不动” | ✓ | — |

结论：
- **单镜重拍、其余保留**已是标配（天工、小云雀、掘金教程里的平台）。
- **整段重写剧本**普遍靠两种办法：“阶段门”（确认后才往下走）和“画布节点隔离”（改上游节点不会自动覆盖下游）。**没有产品明确展示“重写剧本后，哪些镜头受影响 / 哪些手改会被覆盖”的影响分析或 diff**。目前只有 BigBanana 的提示词版本回滚算是半个版本系统。
- 我们仓库最近的提交已经在做“运行剧本前先查影响并确认覆盖项”（见 commit f58104f）。这在调研范围内**领先于国内平台**，应该继续做成正式能力：字段级“锁定 / 手改标记”、重生成预览 diff、按场 / 按镜接受。

## 3. 6–10 个降低复杂度的模式（含适配度：本地工具、GPU 任务以分钟计）

| # | 模式 | 谁在做 | 适合本地分钟级 GPU 吗 |
|---|---|---|---|
| 1 | **阶段门 + 单一“下一步”按钮**：剧本→资产→静帧→视频，每段确认后才进入下一段，文本阶段免费且快 | 小云雀、Seko、天工传统模式、白日梦 | **非常适合**。LLM 阶段秒级，GPU 阶段分钟级，正好在“静帧确认门”前把便宜的活干完。 |
| 2 | **静帧确认门**：先批量出全部首帧，整集在一屏看完、确认后，再排队转视频 | Seko、天工、BigBanana | **非常适合**。图生视频最贵，先锁首帧可以大幅减少返工。 |
| 3 | **资产卡 + @引用**（角色、场景、风格，甚至镜头预设）：建一次，镜头里只写“@林夏 推门”；星标主参考；音色绑在角色卡上 | 即梦（角色管理 / Octo）、Vidu 主体、可灵主体（含音色）、白日梦、BigBanana 衣橱 | **适合**。纯前端 / 数据模型改造，不增加 GPU 负担；可以替代每镜一堆角色、服装下拉框。 |
| 4 | **单镜重拍、其余不动 + 每镜 N 个候选**（宫格或并行版本），版本挂在镜头上，可切换 | 天工片段重拍 / 生成数量、Octo 多版本、LibTV 宫格、BigBanana 九宫格 | **适合但要改造**。本地 GPU 串行，“并行 N 版”会变成“排队 N 版”；建议首帧阶段用便宜的低分辨率多候选或宫格，视频阶段默认 1 版。 |
| 5 | **Agent 一键跑完，但结果是可编辑项目**：给出“自动跑到静帧 / 跑到成片”的入口，跑完落回同一个工作台，可以随时暂停、中止 | LibTV 龙虾、小云雀、Seko；反面是纳逗Pro、早期海螺 | **很适合**。分钟级任务正需要“挂机自动跑”，但必须能暂停 / 中止，并逐镜显示状态。 |
| 6 | **任务托盘 + 逐镜状态**：每个任务有状态（排队 / 运行 / 失败）、ID，失败只重试该镜；生成时界面不锁，可以继续编辑别的镜头 | 天工（状态 + Task ID）、Octo（异步并行）、RunningHub（状态码）、BigBanana 渲染日志 | **必须做**。本地没有积分，但“时间”就是成本：显示排队位次和预计时长，比云平台更有用（RunningHub 都没有百分比）。 |
| 7 | **渐进披露：智能 / 自定义开关**。默认 AI 拆镜、AI 选景别，展开才见每镜时长、运镜、种子 | 可灵智能 / 自定义分镜、天工两种模式、RunningHub 应用 / 工作流两层 | **适合**。直接对应“表单太多”的痛点：每镜默认只露描述 + 角色引用，其余收进“高级”。 |
| 8 | **单页“左列表、右属性 / 中预览”的分镜编辑**，替代多页跳转 | 白日梦分镜页、BigBanana 导演台网格、剪映时间线 | **适合**。把“剧本 / 导演台 / 导出”合成一个以镜头表为主轴的工作台，剧本和导出变成侧栏或阶段视图。 |
| 9 | **重生成影响预览与手改保护**：重写剧本或分镜前列出将被覆盖的段落 / 镜头，手改字段默认锁定，支持按场 / 按镜接受 | 国内平台没找到成熟实现；BigBanana 只有提示词版本回滚 | **最适合我们差异化**。本地生成慢，误覆盖代价高，值得做 diff 和接受 / 拒绝。 |
| 10 | **出口是可编辑工程**：剪映草稿 / XML，而不是只给 mp4 | 剪映文字成片、即梦 Octo（导出 XML 给 PR/FCP）、BigBanana（素材包） | **适合**。导出 FCPXML 或剪映草稿能减少内置剪辑功能，降低界面复杂度。 |

**不建议照搬**：
- 纯无限画布 / 节点（LibTV、Toonflow）。对单人、30–90 秒、固定流程的场景，画布自由度反而增加认知负担；可以只借“节点隔离、并存版本”的思想。
- 积分 / 会员 / 加速通道这类计费 UI。本地工具不需要，只保留“预计耗时”。
- 固定分镜数（讯飞默认 8 镜）。

## 4. 对我们工作台的直接建议（简版）

1. 把四个页面收成**一个“集”工作台**：顶部是阶段条（剧本 · 资产 · 静帧 · 视频 · 成片），主区是镜头表 / 网格，右侧是选中镜头的属性，左侧或抽屉放剧本与资产卡。
2. 每个镜头卡只露“描述 + @角色/@场景 + 首帧缩略图 + 状态”，其余收进“高级”。
3. 每个阶段一个主按钮：“生成全部静帧”和“确认静帧，排队生成视频”。另提供“自动跑到静帧”。
4. 全局**任务托盘**：排队位次、预计时长、逐镜失败重试、暂停 / 中止；生成时不锁界面。
5. 镜头版本条：每次重生成新增一版，可切换、可回滚，不覆盖。
6. 剧本和分镜重生成的三种粒度（整集 / 按场 / 按镜）统一走“**影响预览 → diff → 勾选接受**”。手改字段打标并默认保护（延续现有的“先查影响再确认覆盖”）。
