# 引擎选择指南

AI Studio 的出图、出视频引擎分三类：**本机 ComfyUI**、**网页额度**（经浏览器扩展，用你自己账号的会员 / 免费额度）、
**官方 API**（按量付费）。同一个项目里可以混用：项目定默认引擎，每个镜头还能单独换。

本页的事实来自代码里各引擎的说明（`backend/engines/*/engines.py`）和设计文档
[2026-10-12-seedance-kling-video-design.md](../specs/2026-10-12-seedance-kling-video-design.md)。
标了 **未实测** 的项目是按公开资料写的，还没用真实账号 / Key 跑通过，以实际为准。
各家的价格、额度、会员规则经常变，这里不写具体价格，请以各平台当前说明为准。

## 怎么选

| | 本机 ComfyUI | 网页额度（浏览器扩展） | 官方 API |
|---|---|---|---|
| 花费 | 电费 + 显卡；模型免费下载（遵守各自许可证） | 用你账号的会员 / 免费额度 | 按量付费 |
| 需要 | 本机 ComfyUI、对应模型、有显卡 | Chrome / Edge 装扩展并登录网站 | API Key |
| 稳定性 | 可控，有种子可复现 | 网站改版可能让选择器失效；有每日次数、排队、风控 | 最稳，有明确错误码 |
| 速度 | 看显卡 | 较慢，每个网站一条串行通道 | 看服务端排队 |
| 适合 | 量大、简单镜头、反复调 | 先跑通流程、不想付费、已有会员 | 难镜头、要可控时长 / 尾帧 / 参考图直出 |

镜头抽屉里的**引擎建议**按这个思路自动给建议（只建议，不自动换，见 `backend/domain/engine_advice.py`）：

- 先看硬性要求：有台词要有声引擎、用尾帧要支持尾帧、参考图直出要支持参考图直出、时长不超过引擎上限；
- 简单镜头先挑便宜的（本机 ComfyUI → 网页额度 → 云端 → API）；
- 难镜头（多人同框、大动作、复杂运镜、要对口型……）先挑强模型。代码里把 Seedance 2.x、可灵 v3、Veo 3.x、Sora 2（含即梦 / 可灵网页）
  列为强模型；H3、Wan 2.2、Gemini 网页、Muse 网页为标准档。

出完以后看视频阶段的**抽卡统计**（每镜抽了几次、失败几次、按引擎分开算），按实际可用率调整。

## 图片引擎

| 引擎 | 类型 | 参考图上限 | 说明 |
|---|---|---|---|
| H3 图像 | 本机 ComfyUI | 9 | 参考图锁脸，三视图默认用它（有 H3 时） |
| Krea2 人像 | 本机 ComfyUI | 0（不吃参考图） | 真人写实人像向，适合出定妆照 |
| Z-Image 快速 | 本机 ComfyUI | 0 | 快 |
| ChatGPT 网页 | 网页 | 4 | 不支持负面提示词，没有种子，画幅写进提示词 |
| Gemini 网页 | 网页 | 3 | 同上 |
| Muse 网页 | 网页 | 3 | 同上 |
| OpenAI 图像（API） | API | 8 | gpt-image-1；有参考图走 edits 接口 |
| Gemini 图像（API） | API | 3 | gemini-2.5-flash-image |
| RunningHub 工作流（可选） | 云端 ComfyUI | 按工作流 | 配 `config.yaml` 的 `runninghub` 段 |

不吃参考图的引擎没法用定妆照锁脸，首帧要靠提示词描述外貌；要角色前后一致，首帧优先用能带参考图的引擎。

## 视频引擎

| 引擎 | 类型 | 声音 | 时长 | 尾帧 | 参考图直出 | 备注 |
|---|---|---|---|---|---|---|
| H3 视频（有声） | 本机 ComfyUI | 有 | 默认 5 秒，最长 10 秒 | 否 | 否 | 24 fps，参考图最多 8 张 |
| Wan2.2 图生视频（无声） | 本机 ComfyUI | 无 | 5 秒 | 否 | 否 | 16 fps |
| Gemini 网页（Veo） | 网页 | 有 | 不能指定，约 10 秒 | 否 | 支持，最多 3 张（**上传上限待实测**） | 2026-10-11 实测；要 Google AI Pro / Ultra，有每日次数限制，一段约 3 分钟 |
| Muse 网页 | 网页 | 有 | 写进提示词，只认 3 / 5 / 10 秒，不一定照做 | 否 | 支持，最多 3 张（**上传上限待实测**） | 2026-10-11 实测，约 1 分钟一段 |
| 即梦网页（Seedance） | 网页 | 有（**未实测**） | 5 / 10 / 15 秒 | 支持（**未实测**） | 否 | 默认模型 Seedance 2.0 mini；**选择器待实测** |
| 可灵网页 | 网页 | 有（**未实测**） | 5 / 10 秒 | 否（尾帧上传位还没摸到） | 否 | **选择器待实测** |
| Google Veo（API） | API | 有 | veo-3.0 固定 8 秒；veo-3.1 可选 4 / 6 / 8 秒 | 否 | 否 | 有负面提示词 |
| OpenAI Sora（API） | API | 有 | 4 / 8 / 12 秒 | 否 | 否 | 30 fps |
| Seedance（火山方舟 API） | API | 有 | 2.x：4–15 秒 | 支持 | **支持，最多 9 张** | **未用真实 Key 实跑** |
| 可灵（API） | API | 有（v2.6 / v3） | v3：3–15 秒；v2.x：5 / 10 秒 | 支持（带尾帧时自动用 pro 模式） | 否 | **未用真实 Key 实跑** |

「参考图直出」是镜头抽屉里「生成方式」的一个选项：不出首帧，用场景图 → 构图参考 → 定妆照 / 三视图 → 道具图直接出视频。
现在 Seedance API、Gemini 网页、Muse 网页支持（网页引擎的提示词写明「附图是人物 / 场景参考，不是第一帧」；
首帧模式照旧只发首帧）；其他引擎会在抽屉里禁用这一项并说明原因。

固定时长的引擎（Gemini 每次 10 秒、Muse 只认 3 / 5 / 10 秒）默认按「多拍镜头」排分镜：每个镜头就是一次生成，
分镜在里面按时间戳切 2–4 拍（换景别、换机位），一次出满不浪费。项目设置里「固定时长视频引擎怎么用满」还可以选
「组镜拆分（一次生成拆给几个镜头）」：镜头照常 2–8 秒（各有景别、台词、字幕），相连的几镜排成一组一次生成，导出时按剪切点
拆回各镜；或者「不合并（一镜一生成）」。镜头比一次生成短 1.5 秒以上时，镜头抽屉会提醒浪费几秒，并给「并进下一镜做成多拍镜头」
（组镜模式下是「和下一镜合成组镜」）。两种模式都是改了之后重新生成分镜才生效，已有的镜头不动；组镜也可以在抽屉里手动合 / 拆。

### 即梦 / 可灵网页（状态：选择器待实测）

- 即梦生成页的模型、参考方式、画幅、时长控件已经摸清（[页面探查记录](../notes/2026-10-12-jimeng-kling-web.md)）；
  上传位、结果卡片、视频地址还没摸完，**还没实跑出过一条视频**。
- 当时作者账号看到的即梦价格：Seedance 2.0 mini 5 秒 720P 要 30 积分（原价 45）。积分规则以即梦页面为准。
- Seedance 2.0 系列页面上写着「暂不支持真人人脸」：参考图里有真人照片可能被拒。
- 可灵国内 / 国际站已登录，图生视频（首帧 / 尾帧）入口、积分、结果区还没摸完。
- 区域在设置页「网页出图」里选（即梦 / Dreamina、klingai.com / kling.ai）。

### Seedance / 可灵 API（状态：已实现，未用真实 Key 实跑）

官方文档页是 JS 渲染的，抓不到原文；字段按第三方转述的官方字段表、SDK 示例交叉核对，详见设计文档 §4.5。

- **Seedance（火山方舟 / BytePlus ModelArk）**：默认模型 `doubao-seedance-2-0-260128`，可选 2.0 fast、2.5、1.5 pro；
  用之前要在方舟控制台开通。分辨率默认 720p（1080p 只有 2.0 标准版和 2.5）。首帧、首尾帧、多模态参考三种方式互斥：
  有首帧时不带参考图。1.x 模型不支持参考图直出。结果视频地址 24 小时有效，studio 拿到马上下载。
  国内和海外的 Key 不通用。
- **可灵开放平台**：默认 `kling-v3`。API Key 或 AccessKey + SecretKey（每次请求现签 30 分钟有效的令牌，不存盘）。
  图生视频没有画幅参数，画幅跟着首帧走。常见错误码：1101 欠费、1102 资源包用完、1301 内容审核、1302 / 1303 限流，
  1003 / 1004 鉴权失败多半是本机时钟不准；界面会翻成中文说明。
- 两家的「测试连接」都调「查询任务列表」（只读、不扣费）。

## 文本模型

写剧本、分镜、角色推荐、台词适配、字幕翻译用文本模型，在设置页「默认模型」选，每一步也能单独设：

- **本机**：Claude Code（Agent SDK / `claude -p`，要装 `claude` 命令）、LM Studio（占显卡，用到前先启动）；
- **API**：OpenAI、Anthropic、Gemini；
- **网页**：ChatGPT、Gemini、Claude、Muse（经浏览器扩展，免费额度，较慢）；
- **手动**：任务停下来显示提示词，你贴给任意模型，再把结果贴回任务页。

## Key 和隐私

- API Key 在设置页「API 服务」里填，存在本机数据库，界面和日志只显示掩码；也可以用环境变量，见 [README 的环境变量表](../../README.md#引擎配置说明)。
- 任务目录里的 `workflow.api.json` 不含 Key：Key 只在发请求时放进请求头。
- 网页引擎不读 cookie：扩展在你已登录的标签页里操作。

## 责任

用哪个引擎、生成什么内容、发到哪里，责任在使用者：遵守各网站 / API 的服务条款（部分网站限制自动化使用）、模型许可证（有的不允许商用）、
肖像权和版权，发布时保留 AI 生成内容标识。见 README 的[合规提示](../../README.md#合规提示)。
